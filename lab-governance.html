Data Intelligence – Governance

Act as a Data Steward to profile data, enrich metadata with AI, assign business terms and data classifications, and enforce masking rules for sensitive PII/SPI fields — all through the watsonx.data Intelligence platform.

⏱ 60–75 minutes 👤 Data Stewards, Governance Teams 💻 UI-based, no coding ⚠️ 5–6 active participants (Trial license limit)
Under the Trial license of watsonx.data Intelligence, this lab is available to approximately 5–6 participants due to limited CUH (30 units). Others can observe and learn the concepts.

1. Introduction

This lab demonstrates how to use watsonx.data Intelligence to profile data, enrich metadata with AI, and enforce data protection rules. You'll act as a Data Steward to create and implement governance artifacts that protect sensitive data and ensure data quality.

What This Lab Demonstrates

  • Data Profiling — analyze data structure, types, and content automatically
  • AI-Powered Metadata Enrichment — use machine learning to assign business terms and classifications
  • Data Quality Assessment — automated quality checks and scoring
  • Data Protection — implement masking rules for sensitive information (PII/SPI)
  • Catalog Publishing — make governed assets available for consumption

  • ✅ Configure data quality checks

  • ✅ Publish governed assets to a catalog

  5. Protected Sensitive Data — masking rules for PII/SPI fields

4. Lab Steps

4.1 Open watsonx.data Intelligence Service

  1. Open a new incognito window
  2. Log in to https://cloud.ibm.com using the non-admin credentials provided by instructor
  3. From the IBM Cloud Hamburger menu, select Resource List
  4. Go to AI/Machine Learning → watsonx.data Intelligence
  5. In the Data Fabric section, click Launch
  6. If prompted for a tour, agree to terms and select Skip for now

4.2 Create a Project

The data curation process here uses a project — similar to the Data Lakehouse lab — but this project is created in the shared watsonx.data environment within the Data Fabric context to leverage data fabric capabilities.
  1. From the Hamburger menu, select Projects → View all Projects
  2. Select New Project and configure:
    • Name: Data Intelligence - Governance FirstInitial+Lastname (unique naming is important in the shared environment)
  3. Select your Cloud Object Storage from the list if not selected by default
  4. Click Create
    You may be asked to create a User API Key if you don't have one — click Create to proceed.

4.3 Import Connected Asset from Catalog

  1. Within the project, go to the Assets tab → click Import assets
  2. In the left-hand menu, select Catalog asset → Choose the bootcamp catalog → Data asset → Select the customers table created by the instructor
  3. Click Import

4.4 Browse the Imported Asset

  1. Select your Data Asset that you just imported
  2. Notice that you are currently able to view all fields
  3. On the Profile tab, an overview of data with basic statistics will be automatically created
  4. The Data Quality tab is currently empty — it will be populated after enrichment

4.5 Profile Data for Imported Asset

Profiling analyzes columns of data assets to understand their structure and content — computing statistics, determining data types and formats, classifying data, and capturing frequency distributions.

  1. Select the Profile tab and click Update profile to start profiling.
    This takes approximately 5–10 minutes. You can perform other tasks in the meantime.

4.6 Enrich Data for Imported Asset

Metadata enrichment uses pre-defined data classes and business terms to automatically assign or suggest enrichment during the metadata enrichment process. This saves organizations significant time by reducing manual effort.

4.6.1 Review Enrichment Options

  1. Go back to the project by clicking on its name
  2. Go to the Manage tab → select Metadata enrichment in the left-side menu
  3. Scroll down to Term assignment methods and make sure the following options are selected:
    • Machine learning (ML model assigns terms)
    • Data-class-based assignments (terms assigned based on data class for a column)
    • Name matching (terms assigned based on similarity between term name and asset/column name)
    • Gen AI based term assignment (if available) — available with Trial or Premium SaaS license; uses LLM for domain-specific semantic matching

4.6.2 Create Metadata Enrichment Job

  1. Switch back to the Assets tab
  2. Select New Asset → Enrich data assets with metadata
  3. Enter Name: MDE and select Next
  4. Select Select data from project → Under Asset types, select Data asset and your table → click Select
  5. Confirm your asset is selected and click Next
  6. Set Enrichment Objectives by enabling all of the following:
    • Profile Data
    • Expand Metadata
    • Assign terms and classifications
    • Identify data quality checks
    • Run data quality analysis
  7. Scroll down, select Select categories + → Select [uncategorized] and Customer → click Select
  8. For Primary category for generated terms, select Customer
  9. For Sampling, keep the default Basic
  10. Schedule the enrichment job and click Next
  11. Keep the default (run now) and click Next
  12. Enrichment options will be displayed. Select Create to start the job.
The enrichment process takes approximately 5 minutes. Monitor status in the Jobs tab of the project — it will progress from Started → Running → Completed.

4.6.3 Review Enrichment Results

As the data steward, you will now review the proposed enrichment before publishing it to the catalog.

  1. From the Assets tab, go to Metadata Enrichment asset MDE
  2. Go to the Columns tab to see results.
    Some metadata is generated using AI; others are assigned from governance artifacts. When confidence thresholds are met, metadata is automatically assigned. When the model fails to meet the threshold, it makes a suggestion (shown in purple).
  3. Click the first column address:
    • On the Details tab: see AI-suggested Display name and Description. Click Accept AI suggestion to approve, or click the pencil to edit.
    • On the Governance tab: reject the suggested business term Email. Click + to assign manually → select Address → click Assign.
  4. Click the purple 1 suggested bubble next to risk_score → go to the Governance tab → click Assign to accept the suggestion.
  5. For the Address business term with ambiguity: hover over the business term column for Address → select View more → go to the Governance tab → click + → search for address → select Work Address → click Assign.
  6. Review the Data quality tab to see criteria used to calculate the quality score. For the ssn field:
    • Review assigned Business terms and Data Class
    • Set to SSN and US Social Security Number if not automatically assigned
    • Optionally set Classification to Sensitive Personal Information
  7. For the email field:
    • Review assigned Business terms and Data Class
    • Set to Email and Email Address if not automatically assigned
    • Optionally set Classification to Personally Identifiable Information
  8. Scroll to the right to explore available metadata and data quality scores. Click on a score to see how it was evaluated.
  9. For fields you have reviewed: click the 3-dots at the right end of the row → select Mark as reviewed

4.6.4 Publish Enriched Data to Catalog (One Volunteer Only)

Only one participant with sufficient access should perform this step — coordinate with your instructor on who will volunteer.
  1. Navigate back to the Asset view by clicking on the Asset tab
  2. Select the checkbox next to the data asset and click Publish in the blue bar
  3. Select the bootcamp catalog and click Next
  4. On the Review Assets page, click Publish. This takes a few minutes. Wait for "Request to publish assets completed".

After publishing, the catalog will show updated metadata and governance artifacts for the selected asset.

5. Verify Data Protection

5.1 Verify Data Protection Rule is Being Enforced (Students)

To verify the rule is working, use a non-admin user account (any user in the Techzone resource group aside from the instructor account).

  1. Make sure you are in the watsonx.data instance account
  2. Go to the watsonx.data Intelligence instance
  3. Open the Bootcamp Catalog
  4. Open the data asset from watsonx.data and click the Asset tab
  5. In another window, go to the watsonx.data instance (Resource List → Databases → watsonx.data → Open web console)
  6. Go to Query Workspace → navigate to postgres_catalog → bankdemo → customers_table → generate a Select Statement → run on the Presto engine
  7. Scroll over to the email and ssn columns to observe masking in place:
    • Email address is masked
    • SSN field is masked with different (obfuscated) values
You have demonstrated that watsonx.data allows data stewards to enrich and catalog data just like any other data in their enterprise, and that governance rules (masking) are enforced at query time.

Troubleshooting

Cannot create project

Verify you're logged in to the correct IBM Cloud account (non-admin credentials from instructor).

Enrichment job fails

Check CUH availability — with the Trial license (30 CUH), only 5–6 participants can run enrichment simultaneously. You may need to wait for capacity to free up.

Cannot see catalog

Verify the instructor has granted you access to the bootcamp catalog.

Data protection not working

Ensure data protection rules were configured by the instructor in advance. Confirm you are querying as a non-admin user (admin users own the data and are exempt from masking).
